# PRD v3 — "학식 말고 뭐 먹지?"

> 이 문서는 팀원 각자의 AI(Claude Code/Antigravity)가 기능 논의·개발 시 항상 참고하는 기준 문서입니다. AGENTS.md에서 `@PRD.md`로 자동 불러옵니다.

---

## 1. 배경 및 목적

**문제**: 캠퍼스 학생들이 매일 "학식 말고 뭘 먹을지"를 고민하지만, 학교 주변 상권 정보를 빠르게 확인할 방법이 마땅치 않다.

**목적**: 지도 기반으로 학교 주변 실제 식당 데이터를 제공해, 학생들이 조건(구역/카테고리/가격대)에 맞는 식당을 빠르게 찾도록 돕는다.

**이 제품이 없으면**: 학생들은 검색 없이 늘 가던 곳만 반복해서 가거나, 학식 대신 뭘 먹을지 결정하는 데 불필요하게 시간을 씀.

---

## 2. 타겟 유저

- **1단계 (현재)**: 전남대학교 재학생
- **2단계 (조건부, 추후 상의)**: 반응이 좋고 운영이 감당 가능하면 주변 캠퍼스로 확장 검토. 지금은 논의하지 않음.

---

## 3. 목표 / 관찰 항목

숫자 목표는 지금 정하지 않습니다. 아직 운영해본 적 없는 서비스에서 근거 없는 숫자를 정하는 것보다, **베타테스트 기간(8/9~8/15) 동안 아래 항목을 관찰하고, 그 결과를 보고 다음 단계(3단계) 목표를 정하는 방식**으로 진행합니다.

### 관찰 항목

- **사용 패턴**: 어떤 기능(지도, 필터, 리뷰, 즐겨찾기 등)을 제일 많이 쓰는지 (Vercel Analytics + DB 데이터 기준)
- **이탈 지점**: 어느 화면/단계에서 사용을 멈추는지
- **콘텐츠 생성 활동**: 리뷰·즐겨찾기·제보가 실제로 얼마나 쌓이는지
- **데이터 신뢰도 이슈**: 잘못된 정보(폐업한 곳, 부정확한 위치 등)에 대한 제보나 불만이 얼마나 나오는지
- **정성적 피드백**: 베타테스터에게 직접 "추가하고 싶은 기능", "아쉬운 점"을 물어 수집
- **오류/버그 발생 현황**: 실사용 중 발견되는 에러 빈도와 유형

### 다음 단계와의 연결

위 관찰 결과는 노션의 **사용자 데이터** 페이지에 누적하고, 3단계(다음 방향 결정) 논의 시 이 데이터를 근거로 삼습니다. 이 시점에 필요하다면 구체적인 숫자 목표(재방문율, 사용자 수 등)를 처음으로 설정합니다.

## 4. 기능 요구사항

### 4-1. 핵심 기능 (Phase 1~9, 구현 완료)

| 기능 | 설명 |
|---|---|
| 인증 | 이메일/비밀번호 회원가입·로그인, role 기반 관리자 권한 |
| 지도 탐색 | 카카오맵 연동, 위치 기반 마커, 마커 클러스터링 |
| 검색·필터·정렬 | 식당명/메뉴명 검색, 구역·카테고리·가격대·제휴이벤트 필터, 평점순/거리순/가격순 정렬 |

| 제휴이벤트 | 시작일~종료일 기준 자동 배지 판별(진행중/만료/시작전) |
| 관리자 대시보드 | 회원/식당/리뷰/제보/제휴이벤트/비밀번호 문의 통합 관리 |

## 5. 동작 조건 및 예외 케이스

- 회원가입: 이메일 중복 시 예외 처리
- 로그인: 계정 정보 불일치 시 예외 처리
- 리뷰/즐겨찾기/제보/관리자 기능: 비로그인 상태에서 접근 시 차단
- 검색 결과 없음: "검색 결과가 없어요. 새로운 식당을 제보해보세요!" 문구 노출
- 존재하지 않는 식당 상세페이지 접근 시 예외 처리
- 제휴이벤트: 종료일이 시작일보다 빠르면 등록 시 예외 처리
- 식당 제보 취소: "대기" 상태에서만 가능, 승인/반려된 건은 취소 불가 (반려된 건은 삭제 가능)
- 관리자 권한: 회원가입 화면에서 선택 불가, DB에서 수동 부여만 가능
- 가격 필터: 메뉴 정보 없는 식당은 최저가(minPrice)를 null로 처리, "가격 정보 없음" 표시, 가격 필터 결과에서 제외
- 최저가 계산: 1,000원 미만 메뉴(이벤트성 초저가 항목)는 최저가 계산에서 제외
- 거리순 정렬: GPS 권한 거부 시 학교 정문 고정 좌표로 대체 계산 (하버사인 공식 사용)

## 6. 범위 제외 (이번 단계에서 하지 않는 것)

- **메뉴 사진 직접 등록**: 사장님 계정 시스템이 없어 구조적으로 불가. 리뷰 사진으로 부분 대체. 사장님 계정 시스템 생기기 전까지 보류
- **커뮤니티(게시판) 기능**: 익명 처리·신고 시스템 등 큰 규모 작업 필요. 채택 여부 자체가 미정, 방향부터 팀 논의 필요
- **AI 추천 기능**: 향후 확장 후보, 현재 미착수 (단, 리뷰 선택형 항목으로 관련 데이터는 미리 축적 중)
- **인원수 기반 필터**: 향후 확장 후보, 현재 미착수
- **알림 기능**: 실익 대비 우선순위 낮음, 미착수
