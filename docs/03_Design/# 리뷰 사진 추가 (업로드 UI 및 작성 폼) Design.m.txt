### 📐 UI 상세 스펙

#### ① 사진 추가 버튼 (Upload Trigger)
- **크기:** `84x84px` 정사각형
- **배경:** Background `#f9fafb`, Border 1px `dashed` (점선 `#d1d5db`)
- **모서리:** Radius 8px (`radius-md`)
- **내부 구성:** 
  - 카메라 아이콘 (`📷`)
  - 텍스트: `사진 추가` (Text 12px Bold `#374151`)
  - 카운터: `(1/3)` (Text 12px `#9ca3af`)
- **비활성화 상태:** 최대 3장 업로드 완료 시 `opacity-50`, `disabled` 처리

#### ② 미리보기 썸네일 & 대표 사진 뱃지 (Image Preview)
- **크기:** `84x84px` 정사각형
- **모서리:** Radius 8px (`radius-md`), `object-cover`
- **대표 사진 뱃지 (첫 번째 사진 자동 적용):**
  - 위치: 썸네일 좌측 상단 (`top: 4px`, `left: 4px`)
  - 스타일: Background `primary (#f97316)`, Text `#ffffff` (Text 10px Bold), Radius 4px, Padding `2px 4px`
- **삭제 버튼 (X Icon):**
  - 위치: 썸네일 우측 상단 오버레이 (`top: 4px`, `right: 4px`)
  - 크기: `18x18px` 원형 (`radius-full`)
  - 스타일: Background `rgba(0, 0, 0, 0.5)`, Icon Text `#ffffff` (10px)

### 📐 UI 상세 스펙
- **사진 썸네일 리스트:** Gap 8px, 가로 스크롤(Horizontal Scroll / Carousel)
- **개별 이미지:** `84x84px` 고정, Radius 8px (`radius-md`)
- **클릭 동작:** 이미지 클릭 시 원본 크게보기(Lightbox / Modal) 팝업 실행
