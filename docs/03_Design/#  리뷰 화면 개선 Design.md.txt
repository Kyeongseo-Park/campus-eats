#  리뷰 화면 개선 Design.md

> **개발팀/AI 투입용 가이드:**
> 본 디자인은 기존 배포 스펙(`primary: #f97316`, `radius-md: 8px`, `radius-full: 26px`, `text-sm: 14px`, `text-xs: 12px`)을 100% 준수하며 작성되었습니다.

---

## 1. 식당 상세 내 리뷰 상단 (요약 & 정렬 바)

리뷰 상단에 평점 요약과 정렬 옵션을 깔끔하게 배치합니다.

+-----------------------------------------------------------------------+
|  리뷰 24개                                                            |
|  ★ 4.8  [████████████████████░░] (5.0 / 5)                            |
|                                                                       |
|  [ 최신순 v ]  * 클릭 시: 최신순 | 별점 높은 순                        |
+-----------------------------------------------------------------------+

### 📐 UI 상세 스펙
- **평점 프로그레스바:** Height 8px, Radius 26px, 채움 색상 `primary (#f97316)`
- **정렬 드롭다운/버튼:** Height 32px (`btn-sm`), Radius 8px, Border 1px (`#e5e7eb`), Text 14px
  - **정렬 옵션:** `최신순` (기본값) | `별점 높은 순`

---

## 2. 리뷰 카드 (Review Card) Layout

정보 전달력이 높은 카드 형태 구조로, 향후 사진 추가를 대비한 썸네일 노출 영역을 포함합니다.

+-----------------------------------------------------------------------+
|  (O) 쩝쩝박사      ★★★★★ 5.0                               2026.07.28 |
|                                                                       |
|  후문 바로 앞이라 점심시간에 가기 딱 좋아요.                            |
|  돈까스 바삭하고 양도 진짜 많아서 대학생 가성비 1등 맛집 인정합니다!     |
|                                                                       |
|  +----------+  +----------+  +----------+                             |
|  | [Img 1]  |  | [Img 2]  |  | [Img 3]  |  <- (사진 있을 때만 노출)   |
|  +----------+  +----------+  +----------+                             |
|                                                                       |
|                                                     👍 추천 3  |  신고 |
+-----------------------------------------------------------------------+

### 📐 UI 상세 스펙
- **카드 Container:** Radius 8px (`radius-md`), Border 1px (`#e5e7eb`), Padding 12px~16px
- **유저 헤더:**
  - 프로필 아이콘/사진: `28x28px` 원형
  - 닉네임: Text 14px, Bold (`#111827`)
  - 별점: Text 14px, Color `#facc15` (노란색)
  - 작성일: Text 12px, Color `muted (#6b7280)`
- **본문:** Text 14px, Line-height 1.6 (`leading-relaxed`)
- **사진 미리보기 (Carousel / Horizontal Scroll):**
  - 개별 썸네일 크기: `80x80px` 고정, Radius 8px (`radius-md`)
  - 이미지 핏: `object-cover`
  - 간격: Gap 8px
- **하단 반응 버튼:**
  - 추천 버튼: Text 12px, Background `#fff7ed` (`secondary`), Text `#f97316` (`primary`), Radius 6px, Padding `4px 8px`
  - 신고 버튼: Text 12px, Color `#6b7280` (`muted`)
